/workspace/img2img-pipeline/
├── pyproject.toml          # Auto-generated by uv containing dependencies
├── config.py               # Holds API endpoints & ControlNet structural parameters
├── vlm_client.py           # Encodes image to base64 & requests local vLLM tags
├── webui_client.py         # Submits multi-unit ControlNet + ADetailer payload
├── main.py                 # Core orchestration logic entrypoint
└── start_stack.sh          # One-click startup script for environment & APIs






Running the Code inside Cloud GPU

1. Open your terminal on your home computer and connect to your rented machine via SSH.
2. Drop all project files into /workspace/img2img-pipeline/.
3. Make the launcher executable and run it to stand up your services:

chmod +x start_stack.sh
./start_stack.sh


4. Verify both servers are fully booted up by using tail -f /workspace/vllm.log and checking for standard API startup assertions.
5. Place your target artwork (e.g. input.png) into your pipeline folder and start processing instantly via uv run:

cd /workspace/img2img-pipeline
uv run main.py input.png output.png
